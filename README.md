### What I'm Building

**PixelStack** - Hyper-converged Digital Experience Platform

A headless e-commerce ecosystem I built from scratch: CMS, commerce engine, real-time analytics, 47 Docker services, zero single points of failure. Everything (frontend, backend, DevOps, UI/UX) was built by one person over 9 months, during 100 days of internet blackout in Iran.

At its core is **Artemis**, a plugin runtime that executes React components without rebuilding the host application. It ships a custom compiler, a dependency vault, and an AI-powered plugin builder.

*Status: Production. Codebase: Private.*
